# 繁體中文工作流準則 (Traditional Chinese Workflow Guidelines)

在本專案中，與「宗師」溝通所有的工作流程、現狀更新與技術說明時，必須嚴格遵守以下準則：

## 1. 語系限制

- **一律使用繁體中文 (Traditional Chinese)**。
- 除非是專有名詞 (如 Model, Resource, Git 等)，否則說明文字應避免使用簡體字或過多英文。

## 2. 溝通風格

- 保持恭敬且專業的語氣（如稱呼「宗師」、「弟子」）。
- 邏輯清晰，層次分明，符合本專案的「武林心法」風格。

## 3. 工作流報告 (Workflow Report)

- 在任何 `task_boundary` 或 `notify_user` 的訊息內容中，摘要與狀態更新必須轉換為繁體中文呈現。
- 如果涉及程式碼邏輯的解釋，應使用繁體中文的專業學術術語（例如：回傳值、命名空間、非同步處理）。

## 4. 實施時機

- 所有的 `notify_user` 訊息。
- 專案規格書 (`PROJECT_SPEC.md`) 的描述。
- 實作成果記錄 (`walkthrough.md`)。
